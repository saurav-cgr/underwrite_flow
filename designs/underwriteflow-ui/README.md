# UnderwriteFlow UI screen designs

This interactive, dependency-free prototype contains nine responsive screens:

1. Welcome and role entry
2. Applicant dashboard
3. Product selection
4. Motor application form
5. Document and evidence review
6. Applicant tracking
7. Underwriter queue
8. Human review checkpoint
9. Administration and audit

## Preview

Open `index.html` directly, or serve this directory from any static web server. Use the screen selector in the top bar to move between designs.

All names, applications, documents, rules, and metrics are synthetic. These screens demonstrate triage workflow UX and do not represent real Indian underwriting guidance.

## Interaction highlights

- Role-based entry paths
- Product selection
- Responsive application form
- Evidence source and conflict states
- Queue filters and search
- Human confirmation and override controls
- Audit and system-health views
- Keyboard focus and reduced-motion support
