# UnderwriteFlow

Human-governed insurance triage for fictional Indian motor, life, and health applications, built with FastAPI, LangGraph, React, PostgreSQL, and Docker Compose.

UnderwriteFlow assists with evidence extraction, validation, risk-signal analysis, and triage recommendations while keeping the underwriter responsible for every final route.

## Project status

The product requirements, implementation plan, design system, and interactive UI prototype are complete. Application implementation will proceed one reviewed step at a time.
